Firebase integration steps

  1. Choose your Firebase project or create one at https://console.firebase.google.com
  2. Add Android app and iOS app in the console. Follow the platform guides to download and add the platform config files:
    • Android: download google-services.json and place it in android/app/
    • iOS: download GoogleService-Info.plist and add it to Runner (Xcode) under Runner/Runner
  3. For web, add the firebase config snippet into web/index.html or use firebase_options.dart generated by flutterfire.
  4. Run the FlutterFire CLI to generate platform config (optional but recommended):
    • Install CLI: dart pub global activate flutterfire_cli
    • Configure: flutterfire configure --project "YOUR_PROJECT_ID"
  5. Add missing native changes following the Firebase Flutter docs for each platform:
    • Android: add google services Gradle plugin
    • iOS: ensure CocoaPods and platform version match
  6. After placing config files and adding platform changes, run: 
    flutter pub get
flutter clean; flutter run
